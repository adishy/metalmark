## [P1] Authenticate before accepting an unbounded import body

frontend/nginx.conf:70

`client_max_body_size 0` removes the only bound applied before multipart parsing. This route uses `file: UploadFile = File(...)`, so FastAPI calls `request.form()` and Starlette spools the entire upload before resolving `require_owner` (which also checks CSRF). Consequently an unauthenticated POST can fill the API temporary filesystem with an arbitrarily large non-ZIP file; the JSON/member limits inside the handler run only after that upload completes. I reproduced the ordering against this router: all 524,288 supplied bytes were written before the overridden auth dependency returned 401. Please authenticate before consuming the body and enforce upload/resource limits while receiving it, or retain a finite proxy limit until that path exists.

## [P1] Preserve distinct identities for default-named agent accounts

backend/app/schemas/agent.py:230

Two valid account-creation requests with the same type/currency and no label both create `Added by agent`. `_import_accounts` identifies manual accounts by `(name.strip().lower(), type, currency)`, so exporting those accounts and restoring into an empty household silently merges them. A focused reproduction using this schema and the actual importer with a stub session restored accounts with balances 100 and 200 as one account with balance 100, reporting one created and one matched with no warnings. Their dependent rows are also remapped to the same account. Please give agent-created accounts distinct portable identities/default names, or update account import matching to preserve occurrences, with a round-trip regression case.

## [P2] Describe cost basis in the account currency

backend/app/schemas/agent.py:145

`Holding.cost_basis` is defined in the account currency, and `agent_add_holding` passes this input straight into `upsert_holding` without currency conversion. The new OpenAPI description instead instructs agents to submit the security quote currency. For a EUR-quoted security held in a USD account, an agent following this contract stores a EUR amount that the application interprets as USD. Change the cost-basis description to the account currency (and regenerate the contract); `market_value` correctly remains in the security quote currency.
